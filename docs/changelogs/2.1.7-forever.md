# SQP Forever v2.1.7-forever

First stable (non-beta) release on WoW Forever, following beta.1–beta.9.

Requires RGX-Framework v2.7.13.

- Options rebuilt on the framework's card layout: Global page (general
  behavior beside move/scale/display), Animation page, separate Kill / Loot /
  Percent pages opened from the preview buttons, and a framework-backed
  Profiles tab with create/copy/rename/delete, reset, pagination, and presets.
- Type pages separate ownership: Main Icon card (background style, Text Mode,
  count color), Task Icon card (enable switch, Left Side/Right Side,
  size/offsets, tint), Animation card (main-icon then task-icon animated
  checkboxes first, intensity, per-type header switch).
- Global master switches for the module (per-page headers), task icons, and
  the complete animation set; Animation OFF pauses Quest Toast and restores
  its previous ON/OFF state when re-enabled.
- Classic / Forever backgrounds and Text Mode combine freely on every type;
  the Forever frame keeps its own level-chip structure.
- Reset completeness: Reset All, per-type resets, and per-slider "R" restore
  the baseline set from the tuned profile snapshot; custom saved offsets are
  preserved until explicitly reset.
- Preview locks to the Kill/Loot/Percent page being edited; hovering buttons
  on Global/Animation keeps previewing without stealing the page.
- Plates adapted to the Forever client: secret-GUID progress fails closed
  instead of erroring, overlays yield to Blizzard raid markers, and the
  tooltip progress cache is revision-scoped so plate updates stay cheap.
