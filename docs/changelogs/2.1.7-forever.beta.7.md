# SQP Forever v2.1.7-forever.beta.7

Requires RGX-Framework v2.7.13-beta.1 for the shared Profiles tab and new UI options.

- Profiles tab uses framework database/profile controls.
- Classic / Text / Forever names clarify display style; changing the background
  to Forever preserves numeric counts rather than switching to Text ratios.
- Switching away from Text restores the preview. Global style inheritance is
  restored when per-type overrides are cleared.
- Sliders show values on hover only; reset/font/swatch baselines are aligned.
- Checkbox text is clickable with the matching framework beta.
- Kill/Loot/Percent side controls are inline with their Show Icon setting;
  preview buttons mirror the tab-row gap around the divider.
- Blizzard's decorative left-hand icons are hidden only in the preview.
- Percent sign defaults off; preview toast is centered and plays on request.

Please test reload/profile switching, the narrowest panel width, style cycles,
preview/world parity and animation timing. This is a beta feedback build.
