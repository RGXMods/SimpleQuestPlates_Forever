# SQP Forever v2.1.8-forever.beta.1

Requires RGX-Framework v2.7.13 (tooling reference unchanged); beta channel follow-up after the 2.1.7-forever stable release.

- Preview plate and quest overlay now hide with the options panel and restore
  when it opens; a closed options window never leaves the preview in-world.
- Kill / Loot / % preview buttons keep their selection highlight after the
  pointer leaves, via the framework's new `UI:CreateButton` selection state
  (framework v2.7.14-beta.1 when that beta publishes).

Please test: open/close options with the preview showing a changed type, and
check the Kill/Loot/% row keeps its selection visually after moving off it.
