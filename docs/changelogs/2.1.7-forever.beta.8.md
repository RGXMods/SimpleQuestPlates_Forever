# SQP Forever v2.1.7-forever.beta.8

Requires RGX-Framework v2.7.13-beta.2 for the shared Profiles tab and new UI options.

- Raid markers take precedence: a unit carrying a Blizzard raid marker shows
  the marker with no quest overlay; clearing the marker restores the overlay.
  The addon never prevents, moves, or restyles markers (previously the overlay
  could cover them, looking like missing markers).
- Marker changes re-evaluate visible plates via `RAID_TARGET_UPDATE`, plus the
  existing plate/target/mouseover paths.

Includes everything from beta.7 (Profiles tab, Classic / Text / Forever
styles, hover-only slider values, inline side controls, preview-only
decoration suppression, default-off percent sign, one-shot toast).

Please test: mark a quest mob, confirm the overlay hides and the marker is
fully visible; unmark and confirm the overlay returns; with the addon enabled,
markers appear on every marked target. This is a beta feedback build.
